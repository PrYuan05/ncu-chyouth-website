    守護初心的返鄉實踐

    中央大學彰化校友會深耕家鄉服務逾 20 年，每年寒假號召彰化大專青年返鄉，秉持「陪伴家鄉孩子」的熱忱，於偏鄉國小辦理全程免費之育樂營隊，為家長減輕寒假照顧壓力，給孩子充滿探索與歡笑的童年。

    有任何問題，歡迎聯絡我們
    1. FILE 01

      1:1 黃金陪伴比例

      48 位大專青年志工全程守護 48 位新民國小學童，維持 1:1 細緻照護，密切關注每位孩子的安全、生活自理與情緒狀態。

    2. FILE 02

      手作實踐與科學啟蒙

      打破傳統單向背誦，結合空氣動力實驗、機構連桿與生活烘焙，讓孩子在「動手做」中理解科學原理與生活美學。

    3. FILE 03

      正向品格與團隊協作

      透過沉浸式名偵探柯南解謎任務與大型大地闖關，引導學童建立運動家精神、尊重他人與團隊合作素養。
